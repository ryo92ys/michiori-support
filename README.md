# MICHIORI サポート

iOSアプリ **MICHIORI（世界の名道を歩く）** のサポートページとプライバシーポリシーを公開するためのリポジトリです。アプリ本体のソースコードは含みません。

- サポート： https://ryo92ys.github.io/michiori-support/
- プライバシーポリシー： https://ryo92ys.github.io/michiori-support/privacy-policy.html

GitHub Pages（`main` ブランチのルート）から配信しています。App Store Connectの「サポートURL」「プライバシーポリシーURL」には、この2つのURLを登録しています。

プライバシーポリシーの原文はアプリ本体のリポジトリの `docs/privacy-policy.md` にあります。内容を変えるときは、原文とこのリポジトリの `privacy-policy.html` を同じ作業の中で揃えてください。
